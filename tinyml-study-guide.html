从数到张量：先会读 shape

独立教学补充 · 非原作业答案

要解决的问题：模型收到的“图片”到底是什么？前置：会操作 Python 列表即可。这里不教 Python 语法。

一个标量是一个数；向量是一列有顺序的数；矩阵有两个轴；张量是可以有更多轴的数组。轴的含义来自约定，不能只看维数猜。 本教程图像采用 NCHW：N 是一次处理的样本数，C 是通道数，H/W 是高/宽，四者都是元素个数，不是字节。

  • 灰度图 8×8：单图可以表示为 [1,8,8]，加上 batch 为 [1,1,8,8]。
  • 2 张 RGB 图 8×8：[2,3,8,8]，共 2×3×8×8=384 个元素。
  • 若每个元素 FP32，占 4 byte，数据载荷为 1536 byte；还未计数组对象与对齐。

逐步看一个索引：X[1,2,3,4] 取第 2 张图、第 3 个通道、第 4 行第 5 列（从 0 起计）。X.shape 描述各轴长度，不是像素值。把 [2,3,8,8] 展平为 [2,192] 保留元素数量，但不再显式保留空间轴。

常见误解：reshape 不是 resize。reshape 只是重新组织相同个数的元素；把 8×8 真正变为 4×4 通常要采样或聚合。

检查：4 张 1 通道 8×8 图，INT8 载荷是多少？

点积、矩阵乘与广播

独立教学补充 · 非原作业答案

要解决的问题：模型怎样把输入变成一个分数？前置：张量 shape。

把输入特征 x 与权重 w 一项项相乘再相加，就是点积。x=[1,2,3]、w=[.5,−1,2]，得到 .5−2+6=4.5；再加偏置 b=.5，分数 z=5。x、w 长度均为 3，z、b 为标量。权重是模型学习的参数，输入是样本提供的数。

矩阵乘是许多点积：A 的 shape 为 M×K，B 为 K×N，则 C=AB 为 M×N，Cᵢⱼ=ΣₖAᵢₖBₖⱼ。M/N/K 是计数。一次乘法并累加称为 1 MAC；若乘和加各计一次运算，则近似 2 OP。

跟算：A=[[1,2],[3,4]]、B=[[2],[−1]]，第一行1×2+2×(−1)=0，第二行3×2+4×(−1)=2；输出 shape 2×1，共4 MACs。逐元素乘法与矩阵乘法不是同一个操作。

广播：Y=XWᵀ+b 中 X 为 N×Ci、W 为 Co×Ci、b 为 Co，b 自动按样本重复。N=2、Co=3时，b=[1,0,−1]加到输出的每一行。它不意味着训练了两份 b。一般从最右边比较 shape，各维相等或其中一方为1才可广播。

反例：[2,3] + [2] 不能按想象“给两行各加一个数”；需要把后者变成 [2,1]。不要让偶然相等的维度掩盖错误。

检查：X 为5×4、W为3×4，输出shape与MACs？

检查一下 · 先自己写出答案，再展开核对
Wᵀ为4×3，所以输出5×3；每个输出点积4项，一共5×3×4=60 MACs。bias有3项，在15个输出位置分别相加。

数据集、预测与损失：训练在追什么

独立教学补充 · 非原作业答案

要解决的问题：程序没有手写识别规则，为什么还能分类？前置：线性层与张量。

数据集是一组 (x,y)：x 是输入，y 是已知标签。参数 θ（权重和偏置）控制函数 fθ(x)。训练不断改变 θ，让预测更符合标签；推理使用固定参数预测新输入。

分类头先输出 logits（未归一化分数） z，再用 softmax 转为概率 pᵢ=exp(zᵢ)/Σⱼexp(zⱼ)。z 与 p 都是 K 维，K 是类别数，p 无单位且各项和为1。实现时先减去 max(z) 再取指数，避免溢出。

跟算：两类 logits=[0,0]，概率[.5,.5]。真实类别 y=0，交叉熵 L=−ln(pᵧ)=−ln(.5)≈.6931。若下一次概率[.8,.2]，L≈.2231。这里 ln 是自然对数；概率为1时loss为0。

准确率只问最大分数类别是否正确；loss还关心置信度。同样预测正确，.51 与 .99 的交叉熵不同。batch loss通常取样本平均，因此批量大小改变不应简单使平均loss倍增。

训练集用于更新参数，验证集用于选择结构、阈值等，测试集留到最终评估。不能在测试集上反复挑选最好的量化配置，再把它称作独立测试。

常见误解：概率高不保证现实中一定正确；模型可能分布外失效，也可能未校准。

检查：正确类别的概率从.2提高到.4，交叉熵降低多少？

检查一下 · 先自己写出答案，再展开核对
−ln(.2)≈1.6094，−ln(.4)≈.9163，降低ln(2)≈.6931。类别预测是否变正确还取决于其他类别概率。

导数、梯度与反向传播

独立教学补充 · 非原作业答案

要解决的问题：怎样知道权重该增大还是减小？前置：函数、点积和loss。不要求先会微积分证明。

导数是局部变化率：输入略增一点，输出变化多少。L(w)=w² 时，w从2变2.001，loss从4变4.004001，变化率约4.001；越接近局部点越接近导数2w=4。梯度把每个参数的偏导数收成与参数同shape的数组，指向局部增加最快的方向。

梯度下降取反方向：w_new=w−η∂L/∂w。η是学习率，控制步长；若w=2、η=.1，梯度4，更新到1.6，loss从4降到2.56。若η太大可以越过低点甚至发散，所以一步下降不是永远的保证。

链式法则跟算：单样本x=2、目标y=1，模型ŷ=wx，w=.2，平方损失L=(ŷ−y)²/2。前向：ŷ=.4、误差−.6、L=.18。反向：∂L/∂ŷ=−.6，∂ŷ/∂w=x=2，因此∂L/∂w=−1.2。η=.1更新w=.32，再前向ŷ=.64、L=.0648。

这个平方损失例子用于解释链式法则，与分类使用的交叉熵不是同一个loss。反向传播是沿计算图高效应用链式法则的算法；优化器接收梯度后决定怎样更新。反向传播本身没有自动修改参数。

检查：本例梯度是负数，为何更新让w变大？

检查一下 · 先自己写出答案，再展开核对
w_new=.2−.1×(−1.2)=.32。负梯度说明局部增大w会使loss下降，梯度下降减去负数正是向这个方向移动。

把一次训练步骤串起来

独立教学补充 · 非原作业答案

要解决的问题：前向、loss、backward、step是什么顺序？前置：概率、loss和链式法则。

  1. 取batch：得到输入X与标签y；X是数据，W/b是要学习的参数。
  2. 清梯度：新的独立更新通常应先清空梯度缓存；刻意梯度累积是另一种训练策略。
  3. 前向：计算logits及loss，保存反向需要的中间量。
  4. 反向：由loss计算dW、db；梯度shape分别与W、b相同。
  5. 优化器更新：例如SGD执行W←W−ηdW。然后才进入下一步。

二类单样本跟算：x=[1,0]、W全0且为2×2、b=[0,0]、y=0。logits=[0,0]→p=[.5,.5]→L=.6931。softmax与交叉熵合起来给dz=p−one_hot(y)=[−.5,.5]。于是dW=dz外积x=[[-.5,0],[.5,0]]，db=[−.5,.5]。η=.1后W=[[.05,0],[−.05,0]]，b=[.05,−.05]；新logits=[.1,−.1]，正确概率约.5498，loss约.5981。

符号对照：dz是loss对logits的梯度，dW不是权重本身；one_hot(0)=[1,0]。参数更新后是否更好必须重新前向，不能拿旧loss当新loss。

推理只执行前向并通常关闭梯度记录；训练/评估模式还影响Dropout和BN。eval()与“不记录梯度”是两个不同开关。训练还需梯度、保存的激活和优化器状态，所以内存不能只按推理估算。

检查：一次backward后，W是否已经改变？

检查一下 · 先自己写出答案，再展开核对
还没有。backward计算/累计梯度，优化器step才修改W；手写代码也必须显式执行减去学习率乘梯度。

基础验收：独立算清一个卷积

独立教学补充 · 非原作业答案

要解决的问题：能否脱离公式表做一次资源核算？前置：前五节与第2讲；首次可先做会的部分，再回访。

固定教学约定：batch1、NCHW、输入1×1×8×8；Conv有4个3×3核、stride1、padding1、dilation1、groups1，不含bias。后接ReLU、全局平均池化（GAP）和无bias线性层4→2。

  1. 输出边长 floor((8+2−3)/1)+1=8，所以Conv输出1×4×8×8。
  2. 权重4×1×3×3=36个；每个位置跨1通道做9次乘加，共4×8×8×9=2304 MACs。
  3. ReLU shape不变；GAP将每通道64个空间位置取平均，输出1×4；Linear权重2×4=8，输出1×2，8 MACs。
  4. 权重合计44个，FP32载荷176B；卷积与线性共2312 MACs。这里不把ReLU、池化、softmax的操作强行记成卷积MACs。
  5. Conv输入64元素、输出256元素，同时保存的简单激活载荷320×4=1280B。实际峰值还要看实现缓冲、生命周期与训练模式。

常见误解：4个过滤器不是4次运算，每个过滤器要在64个位置、每位置做9项点积。1 MAC按本教程计为一次乘加；比较FLOPs先确认对方是否用2×MACs。

Output elements = NCₒ

要解决的问题：共享小核怎样识别局部图案？

前置知识：四维张量、点积

直观解释：同一过滤器在每个位置扫描，检测类似局部模式。

符号与分步小算例：X为N×Ci×H×W，教学1×1×8×8；4个3×3核、p=1、s=1给1×4×8×8，权重36、MACs=36×64=2304。

常见误解：输出通道不是输入通道数乘核宽；由过滤器个数决定。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
N / Ci / Co / H / W批量 / 输入通道 / 输出通道 / 高 / 宽整数计数，无物理单位
X / W / b输入 / 卷积权重 / 偏置N×Ci×H×W / Co×(Ci/g)×kh×kw / Co
g / kh / kw / s / p组数 / 核高宽 / 步长 / 每侧填充计数；groups整除Ci、Co

卷积的一个输出元素只访问输入的一个局部窗口，但要沿所有输入通道求和。每个输出通道有一组滤波器；同一组权重在所有空间位置复用。深度学习实现通常计算互相关，即不翻转卷积核，这不影响本课的成本计数。

Y[n,o,h,w] = b[o] + Σi,r,s W[o,i,r,s] · X[n,i,h·stride+r−p,w·stride+s−p]
W shape = (Cₒ, Cᵢ, Kₕ, K𝑤)

计算顺序是：选一个输出通道 → 选输出空间位置 → 取输入窗口 → 各输入通道与核逐元素相乘并累加 → 加偏置。输出空间位置变多，权重数量不变，但复用次数与计算量增加。

手算例： 32×32 输入，Cᵢ=3，Cₒ=16，3×3 核，stride=1，padding=1，N=1。输出为 16×32×32；无偏置参数为 16×3×9=432；MACs=432×32×32=442,368。若有偏置，多 16 个参数。

2.3 Padding、stride、感受野与 pooling

Slides p.31–36

要解决的问题：如何控制输出尺寸？

前置知识：整数除法向下取整、卷积

直观解释：padding保边界，stride降采样，pooling聚合局部值。

符号与分步小算例：Hout=floor((H+2p−k)/s)+1，dilation=1；H=8,p=1,k=3,s=2得4。2×2最大池化[1,3;2,0]输出3，无可训练权重。

常见误解：无参数不等于无计算；边界取整不能省略。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
N / Ci / Co / H / W批量 / 输入通道 / 输出通道 / 高 / 宽整数计数，无物理单位
X / W / b输入 / 卷积权重 / 偏置N×Ci×H×W / Co×(Ci/g)×kh×kw / Co
g / kh / kw / s / p组数 / 核高宽 / 步长 / 每侧填充计数；groups整除Ci、Co
Hₒ = ⌊(Hᵢ + 2p − Kₕ) / s⌋ + 1
Wₒ = ⌊(Wᵢ + 2p − K𝑤) / s⌋ + 1

这里假设 dilation=1、两侧相同 padding。取整不能省略。stride=1 且奇数核时，用 p=(K−1)/2 保持尺寸；stride=2 常用于下采样。零填充、反射填充和边界复制的数值行为不同，输出尺寸相同不代表输出值相同。

感受野是一个输出能依赖到的输入范围。L 个相同 K×K、stride=1 的卷积叠加时，边长 R=1+L(K−1)。更一般的推导：

j₀=1，R₀=1
Rₗ=Rₗ₋₁+(Kₗ−1)jₗ₋₁；jₗ=jₗ₋₁sₗ

j 表示相邻输出在原始输入上的间距。两个 3×3 卷积若第一层 stride=2、第二层 stride=1，则 R₁=3、j₁=2、R₂=7；若两层 stride 都为 1，则 R₂=5。

Pooling 在每个通道内独立聚合，max pooling 取最大值，average pooling 取平均值；通常没有可学习参数，但仍有计算和访存。无参数 ≠ 无开销。

Padding 不只是补零

padding 决定边界如何取值；stride 决定滑窗移动距离。p 是每侧补的元素数，k 为核宽，s 为步长，d 为膨胀率，输出宽为 floor((w+2p−d(k−1)−1)/s)+1。

检查一下 · 零填充和复制填充会改变参数量吗？

2.4 Group、depthwise 与 pointwise 卷积

Slides p.34–35

要解决的问题：如何减少通道间的连接成本？

前置知识：普通卷积的参数公式

直观解释：分组限制每个输出能看见的输入；pointwise恢复混合。

符号与分步小算例：Ci=4,Co=8,k=3,g=2，参数Co(Ci/g)k²=144；g=1是288。g必须整除输入和输出通道。

常见误解：depthwise减少连接，同时改变表达能力，不能宣称完全等价替换。

符号含义形状 / 单位 / 条件

分组卷积把输入与输出通道划分成 g 组，每组只连接自己的输入；要求通道数能被 g 整除。实际权重形状为 (Cₒ,Cᵢ/g,Kₕ,K𝑤)。

算子（忽略 bias） 参数量 P 单样本 MACs
普通卷积 CᵢCₒKₕK𝑤 P·HₒWₒ
g 组卷积 CᵢCₒKₕK𝑤/g P·HₒWₒ
Depthwise，倍率 1 CᵢKₕK𝑤 P·HₒWₒ
1×1 Pointwise CᵢCₒ P·HₒWₒ

Depthwise 的每个通道独立处理空间信息；本课主要讨论 Cₒ=Cᵢ、g=Cᵢ 的情形。它本身不混合通道，所以经常后接 1×1 卷积进行跨通道融合。Pointwise 虽然没有空间邻域，通道较大时仍可能是主要计算来源。

例： Cᵢ=Cₒ=64、3×3。普通卷积每位置需 36,864 MACs；depthwise 加 pointwise 需 576+4,096=4,672，约为原来的 12.67%。这是运算量比例，真实加速需实测。

逐步解释

g 是组数，ci、co 必须能被 g 整除。每个输出仅看到 ci/g 个输入通道，W 的元素数 co×(ci/g)×kh×kw。

跟着算一次

ci=4、co=8、k=3、g=2：权重8×2×9=144；普通卷积8×4×9=288。若输出4×4且batch1，MACs=144×16=2304。

应该得出什么结论

组数增加减少跨通道连接；通常需要其他层混合信息。理论 MACs 减半不保证时延减半。

检查一下 · g=3 能直接用于ci=4、co=8吗？
标准均匀分组不行，4与8都不能被3整除。

Depthwise 是逐通道空间过滤

先看哪里

从底部每种颜色的输入沿同色核读到输出，再看右侧一对一连接；图中每个通道只有自己的空间核。

逐步解释

这是 g=ci=co、通道倍率1的特例。它提取每个通道内部的空间特征，不做跨通道加权；1×1 pointwise 才负责混合。

跟着算一次

ci=4、k=3：depthwise 有4×9=36个权重。再接4→8的1×1层有32个，共68；普通3×3的4→8有288。相同输出面积下算量比68/288≈0.236。

应该得出什么结论

两层组合能大幅减算，但表达方式与普通卷积不同，也有额外中间激活。

检查一下 · 只有 depthwise 能让一个输出混合红、绿两通道吗？
在倍率1的这一层中不能。需要 pointwise 或其他跨通道算子。

2.5 归一化与激活函数

Slides p.37–39

要解决的问题：为什么还需要激活和归一化？

前置知识：均值、方差、梯度

直观解释：激活提供非线性，归一化调整统计尺度，二者职责不同。

符号与分步小算例：ReLU(−2)=0、ReLU(3)=3；对[1,3]，均值2方差1，忽略ε时标准化[-1,1]。γ、β分别缩放与平移。

常见误解：BN的训练批次统计不应在推理时照常更新。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
μ / σ² / ε统计均值 / 方差 / 数值稳定项每统计组一组；ε与方差同量纲

归一化先按指定集合求均值与方差，再进行可学习的缩放与平移：

x̂=(x−μ)/√(σ²+ε)；y=γx̂+β

BatchNorm（图像） 同一通道的 N、H、W 训练依赖 batch 统计；推理通常用运行统计

Sigmoid=1/(1+e⁻ˣ)；ReLU=max(0,x)；ReLU6=min(max(0,x),6)；Leaky ReLU=max(αx,x)；Swish=x·sigmoid(x)；Hard-Swish=x·ReLU6(x+3)/6。GELU、Tanh、ELU 等也是课件提到的激活。

ReLU 会产生零激活，后面可利用动态稀疏性；有界激活可能让范围标定更容易。但替换激活会改变模型功能，不能只按算术成本选择。Transformer 在此讲初步出现，多头注意力在第 7 讲再展开。

符号含义形状 / 单位 / 条件

Latency 是一次请求的完成时间；throughput 是单位时间完成的请求数。流水线、并行和 batching 可以提高吞吐量，同时让单个请求等待更久。只有特定串行情形下，吞吐量才近似等于 1/latency。

课堂例： 设计 A 每 50 ms 完成 1 张图，吞吐量 20 张/s；设计 B 每批 100 ms 完成 4 张图，吞吐量 40 张/s，但单批时延更大。

Tcompute ≈ Operations / Effective compute rate
Tmemory ≈ Bytes transferred / Effective bandwidth
T ≳ max(Tcompute, Tmemory)

课件使用计算与访存可重叠的近似模型。实际还包含启动、同步与框架开销；不能把理论峰值代入后当作测量结果。若访存受限，只减少乘加不一定快；若计算受限，提高带宽也可能收益有限。

能量 E=∫P(t)dt，近似恒功率时 E≈P·T。能量单位是 J，功率单位是 W。课件引用 45 nm、0.9 V 下 DRAM 访问远比算术昂贵的历史数据，核心结论是减少数据移动、增加复用，而非把该绝对数值照搬到现代芯片。

测量习惯（补充）： 固定输入/精度/batch，先 warm-up，对异步设备同步后计时，重复测量并报告中位数与尾部时延。标明是否包含预处理与拷贝，避免比较口径不同。

FLOPs ≈ 2·MACs（本课计数口径）

FLOPs 是运算量，FLOPS 是每秒浮点运算数；整数运算可用 OPs/OPS 表示。MAC 是否被算成 1 或 2 个操作，跨论文比较时必须确认。

顺序执行且能回收缓冲区时，峰值激活可粗估为最大的“当前输入+输出”。有残差、分支、workspace、缓存或无法原地执行时，必须统计同时存活的所有张量。训练通常需要为反向保存多层激活，不能沿用推理峰值估算。

"""独立教学例：纯 Python / CPU，固定玩具图像特征，不是原 Lab 0 答案。
运行：python3 cpu_training.py
类别0=横线，类别1=竖线；这里只训练2维特征到2类的线性分类头。
"""
import math

# 每项为：人为设计的[横向响应, 纵向响应]，以及类别标签。
DATA = [([1.0, 0.0], 0), ([0.8, 0.2], 0),
        ([0.0, 1.0], 1), ([0.2, 0.8], 1)]
W = [[0.0, 0.0], [0.0, 0.0]]  # [输出类别][输入特征]
b = [0.0, 0.0]
LR = 0.5

def forward(x):
    logits = [sum(w * v for w, v in zip(row, x)) + bias
              for row, bias in zip(W, b)]
    exp = [math.exp(z - max(logits)) for z in logits]
    return [v / sum(exp) for v in exp]

def evaluate():
    probs = [forward(x) for x, _ in DATA]
    loss = sum(-math.log(p[y]) for p, (_, y) in zip(probs, DATA)) / len(DATA)
    correct = sum(max(range(2), key=lambda j: p[j]) == y
                  for p, (_, y) in zip(probs, DATA))
    return loss, correct / len(DATA)

print('初始 loss=%.6f, 玩具训练集 accuracy=%.2f' % evaluate())
for step in range(1, 21):
    # 每个优化步骤清空梯度；此处是整个4样本batch的平均梯度。
    dW = [[0.0, 0.0], [0.0, 0.0]]
    db = [0.0, 0.0]
    for x, y in DATA:
        p = forward(x)
        for c in range(2):
            dz = (p[c] - float(c == y)) / len(DATA)  # softmax+交叉熵梯度
            db[c] += dz
            for j in range(2):
                dW[c][j] += dz * x[j]
    if step == 1:
        print('第1步平均 dW=', [[round(v, 6) for v in row] for row in dW])
    for c in range(2):
        b[c] -= LR * db[c]
        for j in range(2):
            W[c][j] -= LR * dW[c][j]
    if step in (1, 5, 20):
        print('更新%02d loss=%.6f, 玩具训练集 accuracy=%.2f' % (step, *evaluate()))
print('x=[1,0] 的概率=', [round(p, 6) for p in forward([1.0, 0.0])])
print('注意：这些是固定玩具训练数据上的结果，不是泛化性能。')

基础路线（CPU也可理解）：GEMM/GEMV → 字节账与Roofline → prefill/decode。进阶路线：PyTorch Profiler → kernel fusion → Flash Attention。实际GPU profiling需要兼容的NVIDIA CUDA设备、驱动和匹配的PyTorch/CUDA环境；Flash Attention还依赖支持的GPU架构、数据类型、head维度及安装环境，具体以本地实验说明及已安装版本为准。无需为读本教程先配GPU。

先把 GEMM / GEMV 算明白

GEMM是矩阵乘：A(M×K)B(K×N)=C(M×N)，有MKN MACs；GEMV是矩阵乘向量，相当于N=1。若将1 MAC计2 FLOP，则F≈2MKN。假设A/B各读取一次、C写一次、每元素b字节，流量下界D≈b(MK+KN+MN)，运算强度I=F/D，单位FLOP/byte。缓存命中和实际算法会改变真实传输量。

手算：M=K=N=4，FP32：F=128 FLOP，D=4(16+16+16)=192B，I≈.667。若N=1：F=32 FLOP，D=4(16+4+4)=96B，I≈.333。这个小例子体现复用趋势，不是GPU基准；真实尺寸越大，复用和实现细节越重要。

然后连接 prefill / decode

对隐藏维d、输出维h的线性投影，prefill一次处理T个输入token：X(T×d)W(d×h)，Tdh MACs，许多token复用W。decode在batch1时每步只产生一个新token：X(1×d)W(d×h)，dh MACs，近似GEMV；持续批处理可增加有效行数。

跟算：T=4、d=8、h=8，prefill为256 MACs，单步decode为64。生成4个token也可能总做256 MACs，但4次串行步骤需要分别调度和访问数据，不能据此判断耗时相同。注意力decode还读取既有KV cache；其流量随上下文长度增长，不能只按线性层推断全部瓶颈。

Hᵢⱼ=∂²L/(∂wᵢ∂wⱼ)Hessian元素若P个参数则完整矩阵P×P

直接关心剪枝引入的损失增量。令 Δw 是参数变化，定义 ΔL=L(w+Δw)−L(w)，这样符号和“损失增加”一致：

ΔL ≈ gᵀΔw + ½ΔwᵀHΔw
g=∇L；H=∇²L

OBD 作三个近似：局部损失近似二次；训练已收敛所以 g≈0；忽略不同参数的 Hessian 交叉项。若删去 wᵢ，Δwᵢ=−wᵢ，于是：

saliencyᵢ ≈ ½Hᵢᵢwᵢ²

同样大的权重，落在曲率更大的方向上，删除代价可能更高。假设局部近似极小点，H 的对角项非负；远离此条件时不能无条件照用。

补充算例： w₁=0.2、H₁₁=100，得分为 2；w₂=1、H₂₂=0.1，得分为 0.05。幅值法会先删 w₁，二阶法会先删 w₂。这说明“权重小”与“损失不敏感”不总相同。

局限在于 Hessian 计算昂贵、对角近似忽略参数耦合、剪太多后局部二次模型可能失效。学案使用上述一致的 ΔL 定义，避免原课件展开式中的符号歧义。

符号含义形状 / 单位 / 条件

4.3 NetAdapt：逐步减少资源的候选比较

Slides p.35–42

要解决的问题：如何在资源约束下公平选候选？

前置知识：验证集、短期微调

直观解释：每轮削减同样资源后比精度，反复向预算靠近。

符号与分步小算例：20ms目标降2ms，比较达到18ms的A(78%)、B(79%)选B；最终充分微调再确认。

常见误解：短微调排名可能与充分训练后的排名不同。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
state / action / reward状态 / 动作 / 奖励结构描述 / 比例等决策 / 标量评价
ΔR / Acc资源削减目标 / 准确率R若是时延则用ms；Acc为百分比

NetAdapt 不依赖上述强化学习控制器，而是按资源下降量逐步适配模型：

  1. 从当前网络出发，规定这轮至少减少 ΔR 资源。
  2. 对每一候选层分别构造压缩方案，使该候选满足 ΔR（通过测量或查表估计）。
  3. 给每个候选做短期微调，再比较准确率。
  4. 选精度最高的候选作为下一轮起点。
  5. 重复至满足全局预算，最后做较长微调。

各候选必须用一致的评估预算，否则比较会偏向训练更多的方案。ΔR 过大可能跳过好解；过小会增加搜索成本。迭代途中自然产生一串精度—资源折中模型。

AMC vs NetAdapt： 前者学习一个顺序决策策略，后者逐步生成和比较候选；两者都强调每层非均匀压缩与目标设备资源反馈。

EIE 是为压缩稀疏网络设计的专用推理引擎。它联合利用：静态权重稀疏（训练后固定的零）、动态激活稀疏（随输入改变的零）、权重共享/低位编码，以及片上存储。

对矩阵向量乘 y=Wx，若 xⱼ=0，可以直接跳过整个第 j 列；若 xⱼ≠0，只遍历这一列的非零权重，做 yᵢ+=wᵢⱼxⱼ。相对于按行做所有 dense 点积，这种数据流天然利用输入零值。

权重按多个处理单元 PE 分布，不同 PE 负责不同输出行。每列用列指针定位区间，存储非零权重的编码及相对行位置；取出后解码，更新本地部分和。课件示意类似压缩列存储的思路，实际实现还有分银行和对齐等细节。

若零模式近似独立：有效乘法数 ≈ P·dweight·dactivation

这是理解收益来源的理想估计，不含索引、队列和不均衡开销。4-bit 编码可以索引较高精度的码本值；存储位宽与实际乘法位宽可以不同。第 5 讲的 K-means 量化会解释这一点。

要解决的问题：稀疏点云卷积先做什么？

前置知识：坐标、卷积核偏移

直观解释：先建立输入点、输出点与核位置的对应map。

符号与分步小算例：输入(1,1)按偏移(+1,0)移到(2,1)，若输出集合含(2,1)则生成一条映射，否则无乘加。

符号含义形状 / 单位 / 条件

点云常占据三维空间中极少的坐标，许多体素为空。将整个空间做 dense 卷积会浪费大量工作。这里的稀疏主要是空间激活坐标稀疏，与对卷积权重剪枝是不同维度。

普通卷积可以让有效支持区域向外扩张。课件展示的 submanifold 思路只在规定的活跃坐标上生成输出，避免反复膨胀；有步幅或改变坐标集合的其他稀疏卷积不一定遵守这一限制。

每个有效关系由三元组 (输入点 i, 输出点 o, 核偏移 k) 表示：

Fout[o] += Fin[i] · W[k]

这里每个点的特征是一个 dense 通道向量。按同一核偏移将映射分组，就得到若干不同大小的 dense 矩阵乘。执行可以概括为：构造 map → gather 输入特征 → matmul → scatter/add 到输出。稀疏问题并不意味着所有内部运算都是标量稀疏算子。

Slides p.105–119

前置知识：批处理、启动开销、稀疏映射

不同核偏移对应的有效点对数量不同，逐个执行会产生许多小 kernel，设备利用率低。完全补齐为 dense 批量运算又浪费太多计算。TorchSparse 通过分组与适量 padding折中：合并相近大小的矩阵乘，允许少量冗余换取更规整执行。

课件的组数实验说明，组太多时调度开销高，组太少时填充冗余高，中间值可能最好；适合的分组依赖数据集和模型。某方案 TFLOP/s 更高却更慢，也可能只是多做了大量无用计算。

TorchSparse++ 进一步涉及内存与计算重叠、行重排、列切分和自动调优。理解目标即可：更少的 padding、连续访问与更高利用率要共同优化，而不是孤立最大化一个硬件计数器。

PointAcc 将映射构造也纳入专用硬件：针对某个核偏移平移输入坐标，把它与输出坐标进行排序/归并并取交集，找出匹配的点对。比如将输入点平移后与输出坐标相等，就生成对应 (In,Out,Wgt) 项。

本讲实验任务： 比较同一模型的 dense、mask 稀疏、真正结构化缩小三种版本，分别记录文件大小、MACs、延迟、精度。如果前两者延迟接近，先检查是否实际调用了稀疏内核，而不是立刻怀疑剪枝准则。

Slides p.1–7

要解决的问题：同一组bit可以表达哪些数？

符号含义形状 / 单位 / 条件

剪枝减少“有多少个数”，量化减少“每个数用多少位”。更少的位数降低权重和激活的存储与搬运，也可能让硬件同时执行更多运算。收益以硬件支持和精度损失可接受为前提。

b 位无符号整数范围是 [0,2ᵇ−1]；二进制补码有符号整数范围是 [−2ᵇ⁻¹,2ᵇ⁻¹−1]。最高位不是简单独立的正负号，而有权重 −2ᵇ⁻¹。例如 8 位补码 11001111 = −128+64+8+4+2+1 = −49。

课堂的基本问题不是“位数越低越好”，而是：在给定分布、任务和执行平台上，怎样分配有限表示能力？权重与激活的分布可能不同，合适的数值格式也可能不同。

FP32 由 1 位符号、8 位指数、23 位显式小数组成。对指数编码 E∈[1,254] 的正常数：

r=(−1)ˢ · (1+F) · 2ᴱ⁻¹²⁷
F=Σᵢfᵢ2⁻ⁱ，i=1…23

隐含的前导 1 不需要存储；23 个 fraction 位对应正常数约 24 位有效二进制数字。指数偏置为 127。不要把指数编码 E 直接当实际指数。

FP32 指数编码 Fraction 含义
E=0 F=0 +0 或 −0
E=0 F≠0 次正规数：(−1)ˢ·F·2⁻¹²⁶，无隐含前导 1
1≤E≤254 任意 正常数
E=255 F=0 ±∞
E=255 F≠0 NaN

因此，最小正正常数为 2⁻¹²⁶，最小正次正规数为 2⁻¹⁴⁹，最大次正规数为 (1−2⁻²³)·2⁻¹²⁶。次正规数使接近零的表示逐步退化，而不是从最小正常数直接跳到零。

FP16 为 1/5/10 位，指数偏置 15；BF16 为 1/8/7 位，指数偏置 127。指数位主要控制范围，尾数位主要控制精度。 BF16 的指数范围接近 FP32，但精细程度低于 FP16，不能说二者“都是 16 bit 所以等价”。

课堂手算： FP16 1100011100000000 分为 1 | 10001 | 1100000000，得到 −(1+0.75)·2²=−7。BF16 的 2.5=1.25·2¹，编码为 0 | 10000000 | 0100000。

5.4 K-means 量化：权重共享与码本

Slides p.22–37

要解决的问题：权重如何共享少量代表值？

量化把连续或大量可能数值映射到有限集合。K-means 量化让权重共享 K 个中心：每个权重存一个中心编号，另存中心值组成的 codebook。中心不需要等间距，可以适应权重分布。

minc,z Σᵢ(wᵢ−czᵢ)²
存储 ≈ P·⌈log₂K⌉ + K·bcentroid bits

若 K=16，编号仅需 4 bit；但中心本身仍可能是 FP32。若 P=1,000,000，理想编号载荷为 500,000 bytes，16 个 FP32 中心额外 64 bytes，尚未计索引与文件开销。

剪枝与量化可以组合：先减少非零权重数，再减少每个非零值的表示位宽。它们也会相互影响，必须重新验证精度，不能直接把独立实验的收益无条件相乘。

Deep Compression 的三阶段是：剪枝与恢复训练 → 权重聚类/码本微调 → Huffman 编码。 Huffman 对高频符号分配较短的码、低频符号分配较长的码，属于无损熵编码；它压缩的是已经量化后的符号，不能恢复前面的量化误差。

SqueezeNet 的 Fire module 先通过 squeeze 层压窄通道，再用 1×1 与 3×3 分支 expand，并拼接输出。它展示了“先设计紧凑结构”与“再做压缩”可以叠加。课件中的 AlexNet/VGG/SqueezeNet 压缩结果是特定实验，不意味着任意模型都能无损达到相同倍数。

5.6 仿射线性量化：scale 与 zero point

Slides p.45–53

要解决的问题：怎样把实数映射到整数格点？

前置知识：刻度、取整、截断

直观解释：S定义间距，Z定义实数0放在哪个整数位置。

符号与分步小算例：S=.2、Z=−1、r=.3，按半格向上：q=round(1.5)−1=1，rhat=.2(1+1)=.4，误差+.1。

常见误解：舍入约定必须写清，半格向偶数与向正无穷不完全相同。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
r / q / r̂原实值 / 整数码 / 重建实值同一个标量或同shape张量；r̂=S(q−Z)

用整数 q 近似实数 r 的常见方式为：

r̂=S(q−Z)
q=clip(round(r/S)+Z, qmin, qmax)
S=(rmax−rmin)/(qmax−qmin)
Z=clip(round(qmin−rmin/S), qmin, qmax)

S>0 为 scale，表示相邻整数对应的实数距离；Z 是 zero point，使真实的零恰好对应整数 Z。量化范围通常应包含零，这对 zero padding 与 ReLU 很重要。若 rmin=rmax，不能直接除以零，需要单独设定有效 scale。

Z 取整后，原实数端点可能不再同时精确映射到整数端点；最终有效范围应由 S(qmin−Z)、S(qmax−Z) 决定。误差包括范围内的舍入误差与超出范围的 clipping 误差。

跟随课堂的 2 bit 示例： rmin=−1.08，rmax=2.12；qmin=−2，qmax=1。S=3.2/3≈1.0667，Z=−1。于是 r=1.48→q=0→r̂≈1.0667；r=0→q=−1→r̂=0；r=2.12→q=1→r̂≈2.1333。

对没有 clipping 的最近舍入，一般有 |r−r̂|≤S/2。存在 clipping 时就没有这个统一上界。不同实现对恰好半格的 ties 有不同规则，跨实现对齐需写清舍入口径。

=Σⱼq𝑤ᵢⱼqₓⱼ − ZₓΣⱼq𝑤ᵢⱼ − Z𝑤Σⱼqₓⱼ + K·Z𝑤Zₓ

一种常用方式是用 [−Q,Q]、Q=2ᵇ⁻¹−1，S=A/Q；另一种 full-range 方式使用全部整数并取 S=A/2ᵇ⁻¹，正端点略小于 A。本课第 5 讲与第 6 讲示例涉及不同口径，不能把它们的 scale 混用。

把 bias 的 scale 设为 Sᵦ=S𝑤Sₓ，Zᵦ=0，得到 qᵦ=round(b/(S𝑤Sₓ))，一般用 INT32。若激活 zero point 固定，可以离线合并修正：

qᵦ′ᵢ=qᵦᵢ−ZₓΣⱼq𝑤ᵢⱼ
Aᵢ=Σⱼq𝑤ᵢⱼqₓⱼ+qᵦ′ᵢ
qᵧᵢ=clip(round(MᵢAᵢ)+Zᵧ)

对 per-channel 权重 scale，S𝑤ᵢ、bias scale 与 Mᵢ 都按输出通道变化。卷积的归约索引 j 对应输入通道与核位置，思路完全相同；输入边界的“真实零”要填整数 Zₓ，而非一律填整数 0。

完整补充算例： w=[0.5,−1]，S𝑤=0.5，q𝑤=[1,−2]；x=[1,2]，Sₓ=0.25，Zₓ=4，qₓ=[8,12]；b=0.25，所以 qᵦ=2。修正 qᵦ′=2−4(1−2)=6；A=8−24+6=−10。取 Sᵧ=0.25、Zᵧ=0，则 M=0.5，qᵧ=−5，反量化为 −1.25，与浮点结果一致。

流程是：低位输入/权重 → 宽位乘加与 bias → 重定标 → 加输出 zero point → 舍入/饱和。量化模型能否快，最终还要看内核是否实际执行了这一流程。

6.1 PTQ：需要决定的不只有 bit 数

Slides p.1–11

要解决的问题：不重训量化需要哪些决定？

前置知识：线性量化、验证集

直观解释：PTQ选择粒度、范围、舍入及哪些层保留高精度。

符号与分步小算例：8bit激活若范围0…25.5，步距.1；改0…255则步距1，位宽相同但分辨率差10倍。

常见误解：PTQ不等于完全不需要数据；校准常需要代表性输入。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
r / q / r̂原实值 / 整数码 / 重建实值同一个标量或同shape张量；r̂=S(q−Z)
S / Z尺度 / 整数零点S为实值每整数步；Z为整数码
qmin / qmax / b整数下上界 / 数据位宽有符号全范围为−2^(b−1)…2^(b−1)−1

PTQ（Post-Training Quantization）从已训练的模型出发，通常不进行完整的任务训练，通过统计或小规模校准确定量化参数。三个核心决策是：粒度（哪些数共用 scale）、范围（保留多大的动态范围）、舍入（每个数向上还是向下）。

同为 INT8，不同 zero point、per-tensor/per-channel、校准数据和 clipping 策略，可能有很不同的精度。权重在推理时固定，可以直接统计；激活随输入改变，需要代表性数据或运行时估计。

对 PTQ 的判断要同时看原模型精度、量化后精度、实际文件/内存和端到端速度。某模型更小，并不意味着更好量化；紧凑网络的冗余更少，可能对误差更敏感。

6.2 Per-tensor、per-channel、group 与 per-vector

Slides p.12–22

要解决的问题：一个尺度应该共享多大范围？

前置知识：张量轴、scale

直观解释：不同通道分布差异大时分别设尺度能保留细节。

符号与分步小算例：1000个权重每32值一组，共ceil(1000/32)=32组；FP16尺度额外64B。

常见误解：group size不是网络分组卷积的groups，两者概念不同。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
r / q / r̂原实值 / 整数码 / 重建实值同一个标量或同shape张量；r̂=S(q−Z)
S / Z尺度 / 整数零点S为实值每整数步；Z为整数码

Per-tensor 让整个权重张量共用一个 scale，开销低；但某个通道的异常大值可能决定所有通道的步长，使小幅值通道大批量变为零。课件以 MobileNetV2 各输出通道幅值差异说明这一问题。

Per-channel 常为每个输出通道保存独立 scale。若第 1 行范围约 ±1、第 2 行范围约 ±100，INT8 对称 per-tensor 用 S≈100/127，第一行只有少量可用格点；per-channel 给第一行 S≈1/127，表示更细。

Group/per-vector 再将一行或张量切成较小块，各自缩放。它改善局部适配，但增加 scale/zero point 存储、读取和计算开销。若 scale 沿归约维变化，就不能总是在整个点积结束后只乘一个统一 scale，内核要配合分组累加或转换。

Per-tensor 最易受跨通道范围差影响 scale 少，实现简单
Per-output-channel 改善通道间差异 每输出通道有元数据与重定标
Group / vector 进一步适应局部分布 更多元数据，归约和布局更复杂

粒度越细不是无条件越优：最终目标是任务精度与真实效率的折中。

6.3 多级 scale 与有效位宽

Slides p.23–28

要解决的问题：为何“4bit”实际超过4bit？

前置知识：摊销、分组量化

直观解释：把尺度/零点也列入每元素账本。

符号与分步小算例：每16值共享16bit尺度，数据4bit，平均4+16/16=5bit；再加16bit零点变6bit。

常见误解：数据类型位宽不等于整个模型有效位宽。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
G / P / s / z组大小 / 元素数 / scale位数 / zero-point位数G、P为计数，s、z为bit
effective bits摊销后有效位宽数据bit + ceil(P/G)(s+z)/P
‖·‖FFrobenius范数元素平方和开根；不同于MSE

VS-Quant 使用较粗粒度浮点因子 γ 与较细粒度整数 scale S_q：r≈γ·S_q(q−Z)。高精度 scale 分摊给较多元素，低开销局部 scale 适应细粒度分布。

有效位宽 = 数据位宽 + 每组元数据位数 / 组内元素数
多级缩放：r≈(q−Z)·S₀·S₁·…

例：4 bit 数据，每 16 个元素增加 4 bit scale，细级开销为 4/16=0.25 bit/元素，即 4.25 bit；还有粗级 γ 的摊销，不能说整个模型绝对恰好 4.25 bit。若每组 32 个 INT4 元素，保存一个 FP16 scale，则理想有效位宽为 4.5 bit/元素，另有 zero point 时还需加上。

课件 p.28 的 shared microexponent 示例，MX4 使用 3 bit 的符号/幅值部分，加每 2 个元素 1 bit 局部指数、每 16 个元素 8 bit 共享指数，得到 3+1/2+8/16=4 bit。MX6/MX9 类似。这里应按该课件的层级定义理解，别把名称相似的其他 MX/FP4 格式当成完全相同。

课件也联系了硬件对低位浮点和微缩放的支持。格式能表达得好只是第一步，scale 的布局和硬件执行粒度必须匹配。

6.4 激活校准：范围与 clipping 的权衡

Slides p.29–38

要解决的问题：应保留离群值还是主体精细度？

前置知识：直方图、clipping

直观解释：范围窄，主体格点密，尾部却饱和。

符号与分步小算例：0…10用255步，S≈.0392；值20被裁剪到10，误差10。若不裁剪到20，S≈.0784，主体分辨率减半。

常见误解：最小权重误差或KL不必对应最小任务误差。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
r / q / r̂原实值 / 整数码 / 重建实值同一个标量或同shape张量；r̂=S(q−Z)
S / Z尺度 / 整数零点S为实值每整数步；Z为整数码
qmin / qmax / b整数下上界 / 数据位宽有符号全范围为−2^(b−1)…2^(b−1)−1
clip / round饱和裁剪 / 取整舍入规则须由实现明确
rmin / rmax选定实值范围与被量化激活同单位
KL / MSE分布差异 / 均方误差指标用于校准代理目标，不等同任务精度

激活范围可以在训练时用指数移动平均统计，也可让已训练浮点模型跑若干校准 batch：

r̂max,t=α·rmax,t+(1−α)·r̂max,t−1

最小值同理。这里 α 是新观测的权重，其他代码可能用相反命名，不能只看参数名复制数值。

全 min/max 保留异常值，但步长变大、主体数据的舍入误差增大；裁剪长尾让主体格点变细，却引入饱和误差。可按样本统计范围，或搜索阈值使以下目标更好：

  • KL divergence： 比较原始激活直方图 P 与量化重建分布 Q，D_KL(P‖Q)=ΣPᵢlog(Pᵢ/Qᵢ)。候选阈值下需聚合尾部、量化并重建到可比较的 bins，再计算分布差异。
  • MSE： 最小化平均 (r−r̂)²。课件介绍 OCTAV 用 Newton-Raphson 思路优化 clipping 阈值，平衡舍入和裁剪误差。

这两个目标都只是任务精度的代理指标，MSE 最小不保证分类准确率最高。校准集应接近部署输入，保留必要的长尾场景；不要用最终测试集反复挑选量化参数。

补充例： 绝大多数值在 [−1,1]，仅少数达到 20。若按 ±20 标定，INT8 步长约 0.157；按 ±1 则约 0.00787，但超出 ±1 的值被裁剪。该不该牺牲异常值取决于它们对任务的重要性。

6.5 AdaRound：最近舍入并不总是最佳

Slides p.39–45

要解决的问题：逐元素最近舍入会错过什么？

前置知识：输出重建、平方误差

直观解释：同层误差会在输出中相加或抵消。

符号与分步小算例：[.49,.49]与[1,1]点积.98；量化[0,0]误差.98，[1,0]误差.02。

常见误解：AdaRound不是改大所有权重，而是基于校准输入优化舍入方向。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
rmin / rmax选定实值范围与被量化激活同单位
KL / MSE分布差异 / 均方误差指标用于校准代理目标，不等同任务精度
λ / V / h(V)正则强度 / 舍入参数 / 软舍入V与W同shape；h(V)在0到1之间

逐权重最近舍入最小化每个权重自己的误差，却忽略多个误差经输入加权后可能相加或抵消。真正影响下一层的是 Wx 与 Ŵx 的差异。

minV ‖Wx−Ŵ(V)x‖²F + λR(V)
Ŵ 在每个格点的 floor / ceil 之间学习选择

用连续函数 h(V)∈[0,1] 松弛向上/向下的二元选择，再用正则鼓励选择接近 0 或 1，最后离散化。这是短期重建优化，因此常被归入 PTQ 方法，不等同于全面 QAT。

补充反例： w=[0.49,0.49]，x=[1,1]，scale=1。最近舍入到 [0,0]，输出从 0.98 变为 0；若取 [0,1]，输出变为 1，误差只有 0.02。单个权重的舍入稍差，合计输出却更好。

AdaRound 的结果依赖校准输入、重建目标和优化效果，不保证对任何输入都更好。小模型 PTQ 的精度敏感性也说明，不能只用位宽给模型分类。

6.6 QAT 与 Straight-Through Estimator

Slides p.46–55

要解决的问题：舍入不可导时怎样训练？

前置知识：链式法则、优化器

直观解释：前向保留量化扰动，反向用替代梯度更新浮点主权重。

符号与分步小算例：上游梯度.3，STE局部导数设1，w梯度≈.3；η=.1使w减少.03，下一次再fake quant。

常见误解：STE是近似，不是round的真实导数。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
Q(W) / W前向假量化权重 / 浮点主权重shape相同；优化器更新W
STE / gW替代梯度估计 / 权重梯度gW与W同shape；不是round真实导数
∂L/∂Q(W)量化模块上游梯度由后续层反向传播给出

QAT（Quantization-Aware Training）在训练/微调前向时模拟部署量化误差，让模型主动适应有限数值网格。通常保留全精度 master weights，避免微小梯度更新被低位表示直接吞掉。

FP master weights→Fake quantize→前向损失→STE 反向→更新 FP 权重

Fake quantization 通常先编码到整数网格，再反量化成浮点值执行。它模拟数值误差，不代表训练过程本身已获得 INT8 内核的加速。

round 的导数几乎处处为零，在跳变点不可导。如果严格按此求导，梯度传不过去。STE 用一个替代导数，最基本形式把量化当恒等映射：

前向：Q(w)=S·round(w/S)
反向近似：∂Q/∂w ≈ 1
因此 ∂L/∂w ≈ ∂L/∂Q(w)

对于带 clipping 的量化，常用区间内传梯度、区间外截断等变体。STE 是有偏估计，不是 round 的真实导数。部署时需要导出整数权重、scale、zero point 与匹配的算子，而不是直接把训练中的 fake-quant 节点视为最终高效模型。

PTQ→QAT 的决策： 先测简单 PTQ；如果误差不能接受，检查粒度和校准；资源允许时用 QAT 恢复。QAT 成本更高，也需要防止训练与部署量化口径不一致。

6.7 二值权重与 XNOR-popcount

Slides p.56–67

要解决的问题：符号乘法能否变成位运算？

前置知识：±1与0/1编码

直观解释：同号给+1，异号给−1，XNOR统计同号。

符号与分步小算例：n=8、popcount=5，点积2×5−8=2；不是5。

常见误解：二值网络通常还有尺度与非二值层，不能只按1bit载荷估整网。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
n / p二值向量长度 / XNOR结果中1的个数整数计数；点积=2p−n
α / Δ缩放系数 / 三值化阈值具体使用位置见正文，通常实标量
popcount / XNOR数1 / 按位同或比特操作，须先明确±1编码

把权重限制到 {−1,+1}，乘法可以变成加减法；若激活也二值化，可用位运算实现点积。确定性二值化用 sign(r)；随机二值化根据 hard-sigmoid 等概率选择正负，会增加随机数生成需求。

只用 sign(W) 会丢掉幅值。对平方误差目标 min‖W−αB‖²，B∈{−1,+1}，解为 B=sign(W)、α=mean(|W|)。缩放因子让二值结果更贴近原张量，但仍有额外计算与存储。

把 +1 编码为 1、−1 编码为 0，两位相同代表乘积 +1，因此：

Σᵢwᵢxᵢ = 2·popcount(XNOR(bits(w),bits(x)))−n

手算： w=[+1,−1,+1,−1]，x=[+1,+1,−1,+1]。XNOR=[1,0,0,0]，点积=2×1−4=−2。若有 α、β，结果还需乘 αβ。打包到机器字时，要屏蔽末尾未使用的 bit，n 是有效元素数。

只二值权重（BWN）与同时二值权重/激活（BNN、XNOR-Net）的精度影响差别很大。课件用 ImageNet 实例说明加速潜力伴随表达能力损失，不能把“1 bit”看作没有代价的压缩。

逐步解释

编码+1→1、−1→0，同号积+1、异号积−1。n是向量长度，p是相同符号个数，所以点积=p−(n−p)=2p−n。

6.8 三值化 TWN 与 TTQ

Slides p.68–70

要解决的问题：三值比二值多了什么能力？

前置知识：阈值、正负尺度

直观解释：加入0可舍弃小权重，TTQ还可学习正负不同尺度。

符号与分步小算例：阈值.2，w=[−.8,.1,.7]映为[−1,0,1]；若负/正尺度.9/.6，重建[−.9,0,.6]。

常见误解：三种取值通常仍需2bit编码或专门打包，不能直接叫每值1.5bit。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
n / p二值向量长度 / XNOR结果中1的个数整数计数；点积=2p−n

TWN 允许 {−α,0,+α}，接近零的权重直接表示为零：

ŵ=+α，w>Δ；ŵ=0，|w|≤Δ；ŵ=−α，w<−Δ

课件给出 Δ≈0.7·mean(|w|) 的经验近似，α 为超过阈值的绝对值均值。它不是对任何分布都精确最优的定律。若没有值超过阈值，实现中要处理空集合。

TTQ 进一步分别学习正、负尺度 wₚ 和 wₙ，表示集合为 {−wₙ,0,+wₚ}，不再强制正负幅值相同。这增加表示自由度，也保留稀疏零值。

三种状态在简单定长编码中通常使用 2 bit；信息论下限 log₂3 不等于硬件天然支持每元素 1.585 bit。三值里的零是否产生稀疏加速，同样取决于内核。

6.9 混合精度与 HAQ

Slides p.71–80

要解决的问题：所有层必须用同样位宽吗？

前置知识：误差敏感度、预算

直观解释：把高精度留给更敏感的层，低精度给冗余层。

符号与分步小算例：两层各100权重，第一8bit第二4bit共150B；全8bit为200B，省25%，未计尺度。

常见误解：平均位宽不能直接预测时延，设备未必高效支持任意混合组合。

不同层对量化的敏感度、计算和访存需求不同，因此可以分别选择权重与激活位宽。若每层两者各有 8 个选项，n 层的组合数为 (8×8)ⁿ=64ⁿ，无法简单穷举。

HAQ（Hardware-Aware Automated Quantization）让自动化策略根据层状态选位宽，结合目标硬件反馈评估时延、能量或模型大小，并在预算内追求准确率。这个闭环与第 4 讲 AMC 相呼应：一个选择剪枝比例，一个选择位宽。

不同平台对某个位宽的支持和代价不同。理论上从 8 位改为 5 位，不代表设备提供原生 5 位乘法，也不代表延迟按 5/8 缩放。混合精度更应结合实际算子与数据布局。

6.1　为什么一个极大权重可能影响其他通道的量化？
参考答案：Per-tensor scale 由整个张量范围决定，极值拉大步长，其他小范围通道只剩很少格点；per-channel/group scale 可减轻这种影响。
6.2　INT4 每 32 个值保存一个 FP16 scale，不存 zero point，有效位宽是多少？
参考答案：4+16/32=4.5 bit/元素；这是理想载荷，未计更粗尺度、对齐和元数据。
6.3　QAT 为什么还要保存浮点权重？
参考答案：小梯度可能不足以改变一个量化格点，浮点主副本允许多次小更新累积；前向仍模拟低位误差。
6.4　减少 clipping 误差一定降低总量化误差吗？
参考答案：不一定。扩大范围减少饱和，但固定 bit 数下步长更大，主体数据的舍入误差可能上升。
6.5　二值向量长度 10，XNOR 后有 7 个 1，未缩放点积是多少？
参考答案：2×7−10=4。若权重与激活分别带 α、β，还应乘 αβ。

MobileNet 的 depthwise-separable block 先做通道独立的空间卷积，再用 pointwise 融合通道。相对于普通 K×K 卷积，参数/MACs 比例为：

(K²Cᵢ+CᵢCₒ)/(K²CᵢCₒ)=1/Cₒ+1/K²

MobileNetV2 的 inverted bottleneck 为 C→tC 的 1×1 扩展、tC 通道的 depthwise、再线性投影到 C′。扩展让轻量 depthwise 在更高维特征上工作，线性投影避免在低维瓶颈处过度破坏信息。此处“线性”描述投影后的激活设计，不能简单从图中所有 ReLU 标签推断任意位置都加 ReLU。

若 stride=1，主要 MACs 约为 HW(tC²+K²tC+tCC′)。当 C 较大，两个 1×1 层仍可能占主导。扩展中间激活有 tC·H·W 个元素，因此 MACs 更少，峰值内存可能更大。

ShuffleNet 用分组 1×1 进一步减少跨通道成本，但组间信息会隔离。Channel shuffle 通过重排通道，让下一次分组看到来自不同旧组的信息。概念上是 reshape/transpose/reorder；实际是否需要数据搬移、是否可融合取决于布局与实现，不能无条件说它“零开销”。

Slides p.33–36

要解决的问题：注意力如何聚合其他位置？

符号与分步小算例：T=4,dk=2，QKᵀ为4×4；矩阵乘需4×4×2=32 MACs，随后乘V还另需计算。

NAS 有三个可分离的组成：搜索空间定义“可以选什么”；搜索策略定义“下一个试什么”；性能评估定义“这个候选有多好”。把三者混为一谈会难以比较方法贡献。

Cell-level 搜索先找一个小单元，再堆叠到整网。常见 normal cell 保持空间大小，reduction cell 降采样。一个 block 可以选择两个输入节点、分别选择变换，再选择 add/concat 等组合方式。

|𝒜|=(2·2·M·M·N)ᴮ=(4M²N)ᴮ

M=5、N=2、B=5 时是 200⁵=3.2×10¹¹。实际 NASNet 的候选节点会随结构变化，还涉及合法连接和同构，因此这个式子是课件设定下的计数练习，不能当成所有 cell 空间的通用规模。

Cell 重复便于迁移与控制成本，但不同 stage 可能需要不同结构。最优小数据集 cell 转到大任务或不同硬件时也可能不是最优。

要解决的问题：随机搜索与系统缩放如何比较？

前置知识：指数、卷积成本

直观解释：深度近线性增加成本，宽度和分辨率通常近平方增加。

符号与分步小算例：近似成本∝d·w²·r²，三者各变1.2倍则成本约1.2⁵=2.488倍；实际层类型不同可偏离。

常见误解：该比例是近似模型，不含设备利用率变化。

符号含义形状 / 单位 / 条件
a / w架构选择 / 网络参数a为离散结构或编码，w为浮点参数集合
A / C(a) / B候选集合 / 候选成本 / 资源预算成本与预算须同单位，如ms或byte

网格搜索对各维度离散取值做笛卡尔积，容易复现但组合爆炸。随机搜索用有限预算采样，在只有少数关键维度时可能比固定网格覆盖更多有用配置，是必须认真比较的简单基线。

EfficientNet 的 compound scaling 协调深度、宽度和分辨率：

depth=αᵠ，width=βᵠ，resolution=γᵠ
α·β²·γ²≈2，α,β,γ≥1

卷积成本粗略正比于深度×宽度²×分辨率²，因此 φ 每加 1，计算约翻倍。通过小规模搜索确定 α、β、γ，再用 φ 控制资源级别。

这个平方律主要针对类似 dense 卷积结构：depthwise 通道成本是线性的；内存和实际延迟也不严格遵循同一式子。Compound scaling 是受约束的结构化搜索，不代表同时任意加宽加深就会最优。

7.9 进化搜索：保留、变异、交叉

Slides p.67–75

要解决的问题：进化搜索如何产生下一批候选？

前置知识：约束、验证集

直观解释：保留好的合法结构，变异/交叉后再评估。

符号与分步小算例：宽度[4,8,16]将第二层从8变4得到[4,4,16]；变异后先重算形状和内存，再评估任务性能。

常见误解：后代不保证比父代好，随机性要求重复和记录种子。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
a / w架构选择 / 网络参数a为离散结构或编码，w为浮点参数集合
A / C(a) / B候选集合 / 候选成本 / 资源预算成本与预算须同单位，如ms或byte
Acc(a) / Pareto候选精度 / 非支配前沿Acc为指定数据集指标；Pareto涉及多个目标

进化搜索维护候选种群，给每个候选计算 fitness（精度或精度与效率的组合），选优秀个体成为父代，再通过变异和交叉产生新候选。

  • 变异： 随机改某层核大小、stage 深度、通道或输入分辨率。
  • 交叉： 从两个父代继承不同结构片段。
  • 约束过滤： 超过时延或内存预算的候选丢弃/重采样，或在 fitness 中惩罚。
  • 精英保留： 让优秀候选不因随机操作立刻丢失，同时避免种群过早失去多样性。

结构变化必须保持形状合法。若性能评估很贵，进化本身再简单也会慢；与共享权重和预测器结合后，才可能在大量候选上有效运行。

补充：Pareto 最优。 若模型 B 精度不低且延迟不高，并至少一项严格更好，则 B 支配 A。未被支配的候选组成前沿；选择哪个点取决于设备预算。单一“最优网络”往往缺少约束。

参考答案：α 控制候选算子选择/混合，W 是算子的实际训练参数。离散化 α 后结构改变，不能直接假定混合网络的精度就是最终结构的精度。

8.2 ProxylessNAS：直接面向目标任务搜索

Slides p.15–19

要解决的问题：搜索时如何避免同时保存所有分支？

前置知识：DARTS、门控

直观解释：二值门让一次前向只走选定路径。

符号与分步小算例：4条分支每条10MB中间激活，串选1条约10MB而非同时40MB；参数和共享输入仍另外存在。

常见误解：O(1)只指候选分支激活随候选数变化的阶数。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
α / w架构参数 / 算子权重两组不同可学习参数
o(x) / softmax(α)候选操作输出 / 混合权重同一边的操作输出须shape兼容
d / w / r深度 / 宽度 / 分辨率缩放系数无量纲；此处w不是权重张量

早期方法常在 CIFAR、小网络、少轮训练或 FLOPs 指标上搜索，再迁移到真正的大任务与设备。这些 proxy 降低成本，却可能改变候选排名。

ProxylessNAS 建立包含候选路径的超参数化网络，把搜索转成训练该网络并移除低价值路径。与始终同时计算所有路径相比，采用路径二值门控，让一次权重训练主要激活单条路径，显著降低候选路径的激活存储。

课件将这一激活开销描述为相对候选路径数 N 从 O(N) 降到 O(1)。它不是整个网络参数或全部搜索状态都变为常数空间；架构参数更新也要按具体算法处理候选比较。

同时使用目标任务和目标设备的延迟反馈，使搜索结果更贴近实际部署。它减少 proxy mismatch，但预测误差、训练预算与搜索随机性仍然存在。

ProxylessNAS 只激活选中路径

先看哪里

先看左侧更新weight，再看右侧更新architecture；深青色路径激活，浅色未激活，下方0/1 gate控制选择。

逐步解释

架构参数给选择概率，二值门在一次前向只保留选定路径，减少同时保存的分支激活；交替更新操作权重与架构参数。

跟着算一次

若4个候选各需10MB中间激活，同时执行约40MB；一次一条约10MB。共享输入、梯度、参数和框架开销未计，不能据此说整网内存恰好减4倍。

应该得出什么结论

O(N)到O(1)描述候选分支激活随候选数N的增长，不是整个模型恒定内存。

检查一下 · 未选分支权重是否从搜索空间永久删除？
不一定。门控是本次采样选择，其他分支在后续步骤仍可被训练/比较。

8.3 硬件反馈：查表与整网预测

相近 MACs 的网络可能有不同延迟：增加深度通常增加串行依赖和 kernel 数；增加宽度可能提高并行利用率，也可能增加带宽压力。同一个结构在 CPU、GPU、手机上排序可能不同。

直接在设备上对每个候选测量最贴近部署，但海量候选会有通信、编译与运行成本。可以先采集数据，构建成本模型：

逐层 LUT：T̂(a)=Σₗt(opₗ, shapeₗ, precisionₗ, device)
整网回归：T̂(a)=f(architecture encoding)

测量条目应包含 kernel、通道、分辨率、stride、batch、位宽与软件设置。只用“卷积”两个字查一个延迟是不够的。搜索结束后应对入围模型在目标设备实测，而不是只报告预测值。

补充稳健选择： 若模型预测 9.9ms、约束 10ms，而预测误差约 ±1ms，它并不是稳妥可行解。可预留余量，或优先实测靠近预算边界的候选。

8.4 OFA：一次训练，多个设备和预算

Slides p.36–46

要解决的问题：同一训练结果能适配多个预算吗？

前置知识：子网、共享权重

直观解释：先训练可覆盖多结构的超级网，再按设备预算选子网。

符号与分步小算例：宽度2种、深度3种、核2种、分辨率2种，若选择独立共24个配置；并非都同样精确。

常见误解：OFA降低重复训练成本，不消除每个设备的最终验证。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
supernet / subnet超级网 / 子网共享权重的大结构 / 选定合法结构
k / d / w / r核尺寸 / 深度 / 宽度 / 输入分辨率具体计数或相对比例，依上下文
LUT目标设备时延查找表键含算子、shape、dtype等，值常为ms

每来一台新设备都重新训练搜索模型，会使设计成本随设备数增长。OFA（Once-for-All）先训练一个支持多种结构的共享权重网络，再从中抽取满足具体硬件预算的子网。

训练 OFA 超网→抽取子网→精度 / 延迟评估→搜索预算内最优→导出并实测

同一组已训练权重可以服务手机、CPU、GPU 等，也可适配同一设备的低电量/高性能模式。大量组合被隐含地包含在超网中，不意味着逐一训练每个子网。

OFA 将昂贵训练与相对便宜的专门化分离。搜索与评估仍有成本；共享权重可能产生子网竞争，因此“取出子网”不自动保证每个子网独立最优。方法的关键在于如何把超网训练得足够好。

8.5 Progressive shrinking：四种弹性

Slides p.47–71

要解决的问题：逐步缩小怎样避免子网崩掉？

前置知识：宽度/深度/核尺寸/分辨率

直观解释：按课程式顺序增加弹性，训练共享参数适应子网。

符号与分步小算例：宽度4缩到2使本层输出通道减半；后继输入也减半，若后继输出不变，其权重与MACs相应减半。

常见误解：跨层维度变化必须协调，不能孤立截断一个张量。

符号表 · 形状、单位与约定
符号含义形状 / 单位 / 条件
supernet / subnet超级网 / 子网共享权重的大结构 / 选定合法结构
k / d / w / r核尺寸 / 深度 / 宽度 / 输入分辨率具体计数或相对比例，依上下文
LUT目标设备时延查找表键含算子、shape、dtype等，值常为ms
N / Ci / Co / H / W批量 / 输入通道 / 输出通道 / 高 / 宽整数计数，无物理单位
X / W / b输入 / 卷积权重 / 偏置N×Ci×H×W / Co×(Ci/g)×kh×kw / Co

一次同时训练所有尺寸会很难。OFA 先训练较大网络，再逐步开放更小结构，使共享权重适应多个子网。课件按分辨率、核大小、深度、宽度逐步展示：

弹性维度 实现思路 必须注意
Resolution 每个 batch 随机选择输入尺寸 激活大小和计算量随分辨率变；预处理一致
Kernel size 从 7×7 中心部分取 5×5，再到 3×3，使用可学习变换矩阵 不是独立存下每个核，也不只做毫无适配的裁剪
Depth 每个 stage/unit 允许跳过后面的部分层 需要合法路径及下采样接口
Width 按通道重要性排序，较小子网保留重要通道 相邻层通道对应关系要同步重排

在课件核变换示意中，5×5 部分被看作 25 维向量，通过 25×25 变换适配；3×3 类似用 9×9 变换。核共享降低训练/存储冗余，也避免较小核完全从头学。

实施补充： 提取子网后，BN 的运行统计可能不适合该子网，常需用代表性数据重新校准统计，再评估。部署应导出真正的子网；若仍让完整超网占内存，就没有兑现对应体积收益。

与结构化剪枝的联系：二者都能改变宽度和深度。区别在于 OFA 预先训练一族可选子网以适应多个预算，而一次性剪枝通常面向一个特定目标。

8.6 Jet-Nemotron 与 PostNAS

Slides p.72–77

要解决的问题：已有大模型结构也能再搜索吗？

前置知识：共享权重、蒸馏、预算

8.7 Zero-shot NAS：不完整训练的代理评分

Slides p.78–82

要解决的问题：不完整训练能看出潜力吗？

前置知识：梯度、代理指标

直观解释：用初始化附近信号快速过滤候选，再对入选者认真验证。

Zero-shot NAS 用初始化状态或少量前/反向计算估计结构潜力，避免为每个候选进行完整训练。这里的 zero-shot 指评估/搜索方式，不是语言模型“零样本提示”的同一概念，也不是完全零计算。

ZenNAS / Zen-score： 随机初始化网络，生成输入 x 与小扰动 x′，比较特征响应差异，再加入 BN 方差相关修正。直觉是衡量可表达性/对输入变化的响应，并补偿归一化的缩放影响。

示意：score ≈ log(特征差异的非负度量) + Σₗlog(BN scale correctionₗ)

课件简写为 log(f(x′)−f(x))；实际不能直接对任意有正有负的向量取标量对数，需要按方法定义做范数/聚合等非负处理。本学案保留原理，不把简写当可直接运行代码。

GradSign： 观察不同样本在初始化点的参数梯度符号是否一致。课件的直觉是，一致性较强可能反映样本优化方向更协调、局部极小点更集中。它是统计代理，不是最终准确率的证明。

这类方法应检查与实际训练后排名的相关性，不能只比较评分绝对大小。随机种子、输入分布和网络类型都可能影响代理；必要时多次采样，并对候选进行进一步验证。

只搜索网络、固定硬件会错过匹配关系；只增加 PE 数也可能受带宽限制。NAAS 将三层设计放进联合空间：

层次 主要变量
Neural network 层数、通道、核、跳接、量化精度
Accelerator PE 数、阵列形状、连接方式、局部/全局 buffer、带宽
Compiler / mapping 循环顺序、tiling、数据流、空间并行维度

卷积可表示成多重循环：batch、输出/输入通道、空间位置、核位置。时间映射决定在一个 PE 上先算哪些循环，影响复用与 buffer；空间映射决定哪些维度分到不同 PE 同时计算，影响通信与负载均衡。

例：沿输出通道并行可以广播同一输入；沿空间位置并行可共享部分权重。二者对互连和本地存储的需求不同，所以最好的映射与网络形状、硬件一起决定。

常见目标 EDP=Energy×Delay，同等精度下越低越好。优化 EDP 不等于单独最小化延迟或能量，最终仍需满足约束。

8.9 非数值参数编码与联合优化

Slides p.88–96

要解决的问题：循环顺序如何放进搜索编码？

前置知识：排序、卷积循环轴

直观解释：给维度优先级，排序后解码为离散执行顺序。

符号与分步小算例：[K,C,X]分数[.2,.9,.5]降序[C,X,K]；把.9改.8不改相对排名，因此顺序不变。

符号含义形状 / 单位 / 条件
K / C / X′ / Y′ / R / S卷积输出通道 / 输入通道 / 输出空间 / 核空间轴各自维度长度为整数；不是量化scale

循环顺序、并行维度不是普通连续数。简单把六个排列编号 0、1、2…，编号差 1 没有稳定的物理含义，优化器难以利用附近关系。

课件采用 importance-based encoding：给固定位置的每个维度一个数值分数；按分数排序得到循环顺序；取前若干维作为并行维度；再结合阵列尺寸与 tiling 解码完整执行方案。并列分数需要稳定的决策规则。

固定维度：[K,C,Y,X,R,S]
分数：[4,6,2,2,3,1] → 排序：[C,K,R,…,S]

分数改变可以诱导有结构的排列变化，比把一个任意排列当作无语义索引更合适，但排序仍是离散操作，不应因此称整个过程完全可微。

联合搜索不断生成网络、硬件和映射候选，评估准确率与 EDP，再用进化或其他优化方法更新。课件展示，连同连接与映射一起搜索，比只改硬件规模获得更好的折中。所有加速器结果仍依赖面积、带宽、工艺、基准等前提，比较时需要相同资源口径。

8.1　Hypernetwork、精度预测器、OFA 超网分别输出/提供什么？
参考答案：Hypernetwork 根据结构生成权重；精度预测器直接给精度估计；OFA 超网提供共享训练好的子网权重。它们可结合，但概念不同。
8.2　ProxylessNAS 的 O(1) 指什么？
参考答案：相对于候选路径数，单路径激活带来的激活存储开销不再随所有路径线性增加；不是整个搜索过程、模型参数或全部状态的总空间为常数。
8.3　OFA 缩小 kernel 时为什么不仅仅独立训练另一个 3×3 核？
参考答案：方法从较大核中心取共享权重，并用可学习变换适配小核，使不同大小子网共享学习结果，摊销训练成本。
8.4　Zero-shot 代理评分高，为什么还要训练和实测入围候选？
参考答案：评分仅与最终性能可能相关，受初始化、数据与空间偏差影响；且不会直接保证目标设备时延和任务精度。
8.5　为什么 NAAS 要同时搜索 mapping？
参考答案：同一网络与硬件在不同循环顺序、tiling 和并行方式下，复用、通信、buffer 和利用率不同；只改 PE 数量可能仍受数据移动限制。

综合案例：把视觉模型放到一个受限设备上

以下全部是教学设定，不是实际测量结果。 假设设备权重预算 1 MB、激活 SRAM 256 KiB、响应预算 30 ms；原模型有 1M 个 FP32 权重，实测延迟 45 ms。最大学习单元的输入为 1×32×56×56，使用 expansion ratio=6 的倒瓶颈。

  1. 先判定权重是否可行。 FP32 载荷 4 MB 超预算；INT8 约 1 MB，但额外 scale、bias、文件头可能使它仍超预算，不能宣布“恰好能放下”。INT4、每组 32 个值配 FP16 scale、不存 zero point 时，载荷约 0.5625 MB。
  2. 检查激活。 扩展激活为 192×56×56=602,112 个元素，即使 INT8 也约 588 KiB，单张量已超过 256 KiB。量化权重不能解决这个瓶颈。
  3. 选择结构改动。 若把输入分辨率减半为 28×28，该扩展激活降到 150,528 bytes，空间相关 MACs 约降到四分之一；但仍需加输入、输出、残差和 workspace，且必须重测精度。还可以减 expansion、做通道剪枝、选择内存更友好的 block 或内存调度。
  4. 选择压缩流程。 用敏感度/AMC/NetAdapt 分配通道比例，微调后重新校准量化；或者用 TinyNAS/OFA 搜索满足内存和时延的子网。不是把所有技术依次堆上去就一定更好。
  5. 估计时延上限。 假设 45 ms 中只有 70% 的时间能被某内核优化，且该部分快 2 倍，则总时延≈45×(0.3+0.7/2)=29.25 ms。只比 30 ms 略低，仍应留余量并检查尾部时延；若该内核根本不支持模型的量化/稀疏格式，估计不成立。
  6. 闭环验证。 对最终导出的模型实测任务质量、文件大小、峰值内存和时延。量化、BN 统计或剪枝后的变化都应反映在最后的部署版本里。

  • 目标设备真正缺的是容量、带宽、算力还是响应时间？

  • 减少的是参数、MACs，还是已经测到的端到端时延？
